Название игры: "Росинки для грибочка" / "Mushroom's Dew"
"Росинки для Грибочка" – это казуальная 3D-игра-исследование для ПК, где игрок управляет грибочком на милой полянке.
Грибочек собирает росинки и поливает увядшие цветы, а барашек-квестодатель даёт задания и помогает находить спрятанные росинки. За собранные росинки можно покупать кастомизацию грибочка. Цель игрока: успеть полить все цветы за определённое время.

Жанр: казуальная 3D-игра-исследование с элементами лёгкого экшена.
Платформа: ПК.
Основное действие: сбор росинок, полив цветов, выполнение заданий барашка.
